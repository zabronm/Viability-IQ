ASSESSMENT SALES PERSISTENCE FIX
================================

Root cause
----------
The Sales page displayed DIY Tools Accessories with a total of 187,580, while
cashflow showed zero because the edit form rebuilt only part of AssessmentSales.

On update it unintentionally wrote:

    ProductCategoryId = 0
    Active = false
    TotalNoVAT = 0
    TotalWithVAT = 0

The page's vw_assessment_sales_list still returned the row, but the cashflow
engine correctly loads only active AssessmentSales rows. The discrepancy was
therefore caused by persistence, not the cashflow arithmetic.


Installation order
------------------
1. Apply CashflowIncomeTypes_2026-09-14.
2. Apply CashflowIncomeTypes_CategoryLink_Fixed_2026-09-14.
3. Copy:

   Files\ViabilityIQ.Web\Components\Pages_Assessments\PageFormComponents\IncomeSalesFormComponent.razor.cs

   into the matching production path.

4. Back up the database.
5. Review and run:

   Files\ViabilityIQ.Modules\Database_Sql\RepairAssessmentSalesCategoryLinks.sql

   It defaults to:

       DECLARE @AssessmentId BIGINT = 4;

   Change that value before execution when repairing a different assessment.

6. Rebuild and restart:

       dotnet build ViabilityIQ.sln


What the form now preserves
---------------------------
Existing rows are loaded from tblAssessmentSales by primary key before editing.
This preserves:

- ProductCategoryId
- Active
- created/modified audit fields
- category relationship
- VAT configuration
- fields not exposed in the form

On every save it recalculates:

- all 12 monthly columns;
- TotalNoVAT;
- VATRate;
- TotalWithVAT.

Projection invalidation is published only after a successful database save.


Repair-script safety
--------------------
The script:

1. Reactivates non-zero sales rows that still have a valid active category.
2. Repairs ProductCategoryId=0 only when the description matches exactly one
   active category in the same assessment.
3. Synchronizes IncomeTypeId from that category.
4. Recalculates annual totals.
5. Displays the repaired rows for review.

Ambiguous descriptions are not automatically linked.


Expected result for Assessment #4
---------------------------------
After repair and application restart:

- DIY Tools Accessories remains linked to its Sales category.
- Active is true.
- TotalNoVAT is 187,580.
- The Total Sales KPI is 187,580 when the row is VAT-exclusive.
- If VAT is enabled, the VAT-inclusive Profit Summary Sales line displays the
  corresponding gross value while VAT-exclusive KPIs remain 187,580.
