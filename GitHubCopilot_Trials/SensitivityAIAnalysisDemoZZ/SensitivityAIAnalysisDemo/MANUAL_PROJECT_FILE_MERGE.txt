10. HTTP 400 troubleshooting
----------------------------
An HTTP 400 means Gemini rejected the request body; it does not indicate a missing
API key or network failure. Ensure GeminiSensitivityAiAnalysisService.cs is the
latest package version. Its response_format must be:

  response_format = new
  {
      type = "text",
      mime_type = "application/json",
      schema
  }

The Gemini schema must not contain the unsupported string constraints `minLength`
or `maxLength`, or the unsupported array constraint `uniqueItems`. Text lengths,
duplicate evidence keys and unknown evidence keys are validated by Viability.IQ
after the structured response is received.
