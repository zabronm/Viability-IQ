DATA ENTRY SAVE WORKFLOW REFINEMENT
===================================

Purpose
-------
This package standardizes repeated data entry for Assessments, Assets, Sales,
Stock, Expenses, and Loans.

New records:
- Save successfully.
- Refresh the calling page grid and KPI/summary data.
- Refresh application navigation badges or active-assessment indicators.
- Clear the form to a new record while keeping the off-canvas open.

Existing records:
- Save successfully.
- Refresh the calling page grid and KPI/summary data.
- Refresh application navigation badges or active-assessment indicators.
- Close the off-canvas.

Deployment
----------
1. Back up the application or commit the current source tree.
2. Copy the complete contents of the Files folder to the solution root.
3. Preserve the relative folder structure and overwrite the listed files.
4. Build the solution:

   dotnet build .\ViabilityIQ.sln --no-restore --nologo --verbosity quiet

5. Test add and edit flows for Assessments, Assets, Sales, Stock, Expenses,
   and Loans.

Important behavior
------------------
- SaveResult.SavedAndNew is used for new records. It keeps the panel open and
  requests a clean form.
- SaveResult.SavedAndClose is used for edits.
- Both off-canvas services publish successful save notifications.
- MainLayout refreshes entity-count badges immediately after global saves.
- MainLayout_Assessment revalidates the active assessment and refreshes its
  Assets, Sales, Stock, Expenses, and Loans indicators after module saves.
- One-off editors such as asset movements, loan repayment schedules, VAT
  adjustments, assumptions, and bulk imports retain save-and-close behavior.

Validation
----------
The package was overlaid onto the synchronized validation solution and built
successfully with 0 errors. Existing unrelated warnings remain.
