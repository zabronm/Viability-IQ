PRINTABLE ASSESSMENT BALANCE SHEET
==================================

Prerequisite
------------
Deploy AssessmentBalanceSheet_2026-09-16 first.

Deployment
----------
Copy the contents beneath Files into the solution root, preserving paths, and
replace the existing Balance Sheet files.

The page uses the same JavaScript print lifecycle as the existing Asset Summary
and Asset Detail pages:

  viqAssetDetailsCharts.print("balance-sheet")

Ensure assessmentAssetDetailsCharts.js remains loaded by the application.

Print behavior
--------------
- Adds a Print Full Page button.
- Disables printing while balance-sheet data is loading.
- Temporarily expands all balance-sheet findings before printing.
- Restores the user's collapsed/expanded alert state after printing.
- Hides the print button, dismiss button, and alert toggle on paper.
- Prints on A4 landscape with narrow margins.
- Fits all M1-M12 columns without horizontal clipping.
- Removes sticky table positioning for print.
- Repeats the month header when the statement spans pages.
- Preserves meaningful section, total, equity, and status colors.
- Starts the balance-sheet statement on a clean page after metrics and alerts.
