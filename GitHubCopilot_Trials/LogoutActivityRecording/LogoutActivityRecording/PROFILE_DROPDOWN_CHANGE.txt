PROFILE DROPDOWN - LOGOUT-ONLY CHANGE
=====================================

File to edit:

ViabilityIQ.Web\Components\Pages\Identity\ProfileDropdownComponent.razor


1. REPLACE THE SIGN OUT BUTTON
------------------------------

Replace:

<button class="profile-dropdown-item w-100 text-start border-0 bg-transparent"
        @onclick="LogoutAsync"
        type="button">
    <i class="bi bi-box-arrow-right me-2"></i> Sign Out
</button>

with:

<a href="/logout"
   class="profile-dropdown-item text-danger"
   @onclick="CloseProfileMenuImmediately">
    <i class="bi bi-box-arrow-right me-2"></i> Sign Out
</a>


2. DELETE THE DIRECT LogoutAsync METHOD
---------------------------------------

Delete:

private async Task LogoutAsync()
{
    ...
}

Direct SignInManager.SignOutAsync or AuthService.LogoutAsync calls bypass the
mandatory activity-recording endpoint.


3. OPTIONAL CLEANUP
-------------------

Remove these injections only if nothing else in the component uses them:

@inject SignInManager<ApplicationUser> SignInManager
@inject NavigationManager NavigationManager
@inject CustomAuthenticationStateProvider AuthenticationStateProvider
