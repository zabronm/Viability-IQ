DEBTORS/CREDITORS PROFILE ENTRY MODE - IMPLEMENTATION
=====================================================

Purpose
-------
This package refactors DebtorsCreditorsComponent so users may capture either:
- Percentage profiles; or
- Actual ageing balances.

In Actual Values mode all five ageing buckets are genuine input amounts. The component
converts each side independently to a percentage profile totalling exactly 100%. Those
percentage fields remain the authoritative values consumed by the projection engine.

Deployment
----------
Copy all files beneath Files to the matching solution paths.

No database change is required. The existing EntryMode, percentage fields and amount
fields in tblAssessmentDebtorsCreditorsProfile are reused.

Verification
------------
1. Build ViabilityIQ.sln.
2. Open Assessment Assumptions > Sales & Working Capital.
3. Select Actual Values.
4. Enter, for example, debtor amounts:
   0-30 = 90,000; 31-60 = 35,000; all other buckets = 0.
5. Confirm the preview shows:
   0-30 = 72.00%; 31-60 = 28.00%; total = 100.00%.
6. Save and reload. Confirm amounts and percentages persist.
7. Switch to Percentages and confirm the converted profile remains available.
8. Change a percentage bucket and confirm 0-30 automatically balances the total to 100%.
9. Save and confirm the projection views continue using the percentage fields.

Behavior notes
--------------
- A zero-balance side retains its existing percentage profile, so a business with no
  current debtors or creditors can still save a valid forward-looking profile.
- Negative values are prevented and normalized to zero.
- Percentage buckets above 30 days are proportionally normalized if they exceed 100%.
- Switching modes preserves the existing amount total where one is available.
- Bad debts, average payment days and VAT-inclusive status remain editable.
- Projection engine files are not changed.

Rollback
--------
Restore the prior DebtorsCreditorsComponent.razor and .razor.cs. Remove the new
DebtorsCreditorsComponent.razor.css if it did not exist before deployment.
