CASHFLOW BUSINESS INDICATOR UI FIX
==================================

This package contains replacements for:

ViabilityIQ.Web/Components/Pages_Assessments/ProjectionComponents/
  CashflowBusinessIndicatorComponent.razor
  CashflowBusinessIndicatorComponent.razor.css

Copy the two files beneath Files into the matching production directory.

Changes
-------
- Replaces the RenderFragment-generated status rows with normal Razor markup so
  Blazor scoped CSS is applied consistently.
- Prefixes every component selector with cfbi- to prevent application-wide CSS
  collisions.
- Adds a responsive gap between metric labels and classifications.
- Uses the following status palette:
  green = strong/very good
  blue = good
  amber = fair/adequate/caution
  red = weak/critical/negative
  grey = unavailable/neutral
- Gives Return on Assets and Current Ratio their own thresholds instead of
  inheriting the Asset Turnover classification.

The component requires IndependentCashflowProjectionComponent.cs from the
AssessmentDashboardUI_Refined_2026-09-15 package.
