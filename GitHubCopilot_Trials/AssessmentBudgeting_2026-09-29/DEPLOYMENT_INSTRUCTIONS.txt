VIABILITYIQ ASSESSMENT BUDGETING MODULE
Package date: 2026-09-29

PURPOSE
-------
Adds an assessment-owned budgeting workspace. A user creates one active budget
inside an assessment from the assessment's current 12-month cash-flow projection.
The imported projection is stored as a comparison snapshot; subsequent edits affect
only the budget.

FEATURES
--------
- Route: /assessment/budgets/{AssessmentId}
- Uses MainLayout_Assessment.
- Linked from the Budgets tile in QuickAccessComponent.
- Creates the initial budget from ICashflowProjectionService.
- Monthly Profit & Loss and Cash Flow planning lines.
- Budget, Projection and Variance display modes.
- Automatic Gross Profit, EBITDA, EBIT, Profit Before Tax, Total Inflows,
  Total Outflows, Net Cash and Closing Cash calculations.
- Budget alerts for cash deficits, loss-making months and adverse profit variance.
- Draft, Submitted and Approved workflow.
- Approved budgets are locked until a Tenant Owner or Tenant Administrator reopens them.
- Projection refresh updates comparison values without overwriting budget entries.
- Optimistic concurrency through SQL Server ROWVERSION.
- Tenant and assessment read/write authorization.
- Toast-based user feedback and server-side exception logging.
- Status-transition audit history.

DEPLOYMENT ORDER
----------------
1. Back up the application database and deployed application files.
2. Run:

     DatabaseScripts\2026-09-29_AssessmentBudgeting.sql

   The script is transactional and creates:
   - tblAssessmentBudget
   - tblAssessmentBudgetLine
   - tblAssessmentBudgetStatusHistory

3. Copy the contents of Files into the application source, preserving paths.
4. Confirm this registration remains in:

     ViabilityIQ.Infrastructure\Extensions\ServiceCollectionExtensions.cs

     services.AddScoped<IAssessmentBudgetService, AssessmentBudgetService>();

5. Restore, build and deploy:

     dotnet restore .\ViabilityIQ.sln
     dotnet build .\ViabilityIQ.sln --no-restore

CONFIGURATION
-------------
No new application setting, secret, email configuration or AI-provider setting is
required. The package does not replace the Groq/Gemini registration file in the
Application project.

AUTHORIZATION
-------------
- Tenant Owner and Tenant Administrator:
  create, edit, submit, approve and reopen budgets in their authorized scope.
- Branch Manager:
  create, edit and submit budgets for assessments in the manager's authorized scope.
- Viewer:
  read approved/submitted/draft budget information where assessment access is granted,
  but cannot create or change a budget.
- Every service operation independently validates TenantId and assessment access.

ROLLBACK
--------
Restore the replaced application files from backup. If no budget data must be retained,
drop the new tables in dependency order:

  DROP TABLE dbo.tblAssessmentBudgetStatusHistory;
  DROP TABLE dbo.tblAssessmentBudgetLine;
  DROP TABLE dbo.tblAssessmentBudget;

Do not drop the tables if budget records must be retained.
