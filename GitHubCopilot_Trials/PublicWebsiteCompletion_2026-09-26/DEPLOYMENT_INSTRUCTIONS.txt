VIABILITYIQ PUBLIC WEBSITE COMPLETION
Package date: 2026-09-26
Primary route: /website/index

PURPOSE
-------
This package completes the existing public website as a responsive one-page
experience and completes the live contact-submission service.

The page now includes:
- Branded navigation using /images/ViabilityIQ_logo_0.png.
- Hero content and the existing dashboard preview image.
- Platform capabilities based on implemented ViabilityIQ modules.
- Four-step assessment workflow.
- Target audience section.
- Standard and Open Plan positioning.
- Physical address and WhatsApp contact options.
- Live contact form with subject selection, validation and consent.
- Responsive navigation and footer.

The form:
- Stores every accepted submission in dbo.LeadSubmissions.
- Sends an SMTP notification to the configured contact recipient.
- Retains a stored submission if email delivery fails and reports that partial
  outcome clearly to the user.
- Uses parameterized SQL.
- HTML-encodes all user content before placing it in an email.
- Includes a honeypot field and a short client-side repeat-submission delay.
- Does not log the submitted message or contact details.

EMAIL CONFIGURATION
-------------------
The contact request is stored before email is attempted. Configure SMTP using
environment variables or another production secret provider:

  EmailSettings__SmtpServer
  EmailSettings__Port
  EmailSettings__SenderAddress
  EmailSettings__SenderPassword
  EmailSettings__EnableSsl
  Website__ContactRecipient

Website__ContactRecipient is the mailbox that should receive website enquiries.
If it is omitted, the service uses EmailSettings__SenderAddress as the recipient.

PowerShell example for the current process:

  $env:EmailSettings__SmtpServer = "smtp.example.com"
  $env:EmailSettings__Port = "587"
  $env:EmailSettings__SenderAddress = "noreply@example.com"
  $env:EmailSettings__SenderPassword = "<smtp-secret>"
  $env:EmailSettings__EnableSsl = "true"
  $env:Website__ContactRecipient = "enquiries@example.com"

Never place the SMTP password in source control. For IIS, Azure App Service or a
container platform, configure the same names in that platform's protected
application settings or secret store and restart the application.
