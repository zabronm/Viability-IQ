VIABILITYIQ IDENTITY AND SECURITY UI CLEANUP
Package date: 2026-09-30

PURPOSE
-------
This package repairs the Identity account-settings, change-password, registration,
and password-recovery user experience.

CHANGES
-------
1. Account Settings
   - Restores consistent sizing, spacing, focus states, and icon padding for Blazor
     InputSelect and InputDate controls.
   - Replaces each custom/native duplicate checkbox pair with one accessible Bootstrap
     checkbox.
   - Adds explicit labels and responsive small-screen layout.
   - Removes inline success/error alerts and routes feedback through ToastService.
   - Accurately reports that the current settings component updates session state only;
     it does not claim that preferences were persisted.

2. Change Password
   - Restores full-width password controls and correct left/right icon spacing.
   - Adds accessible labels, autocomplete hints, and labelled password-visibility
     buttons.
   - Removes inline success/error alerts and routes all feedback through ToastService.
   - Preserves the TenantUserRoleManagement temporary-password workflow:
       * MustChangePassword is cleared only after a successful password change.
       * A failed restriction update is logged and shown as an error Toast.
       * Successful changes continue to /home.

3. Registration
   - Includes the corrected registration view in which anonymous users see only the
     Sign In link.
   - Back to Dashboard is rendered only when IsEditProfileMode confirms that the user
     opened the form while authenticated.

4. Forgot Password
   - Adds /identity/forgot-password as the canonical route.
   - Retains /forgot-password as a compatibility alias.
   - Corrects the Login page's account-recovery footer link so anonymous users are not
     sent to the authenticated Change Password page.

5. Identity layouts
   - Adds ToastComponent to MainLayout_Identity and MainLayout_Blank so ToastService
     messages are visible on all affected Identity pages.

PREREQUISITES
-------------
Deploy these packages first, in this order:

  1. ApplicationReports_RuntimeCorrections_2026-09-26
  2. TenantUserRoleManagement_2026-09-29
  3. TenantUserRoleManagement_UIRefinement_2026-09-29

The TenantUserRoleManagement package supplies ApplicationUser.MustChangePassword and
the mandatory first-login password-change workflow preserved by this package.
