VIABILITYIQ PERSISTED REGIONAL SETTINGS CORRECTION
Package date: 2026-09-30

PURPOSE
-------
This package fixes the remaining province and tenant-branch persistence problems in
My Profile and Account Settings.

ROOT CAUSES
-----------
1. UserRepository saved ProvinceId through Identity but did not select ProvinceId when
   reloading the profile. The profile therefore reopened with Province 0, making the
   Save button invalid and preventing a Toast-producing submit.
2. Account Settings still displayed hard-coded sample provinces and branches. Its Save
   handler waited briefly and changed no database record, so /home correctly continued
   to resolve the active tenant membership as Unassigned.

CHANGES
-------
1. UserRepository now selects ProvinceId for both email and user-ID profile reads.
2. Account Settings now loads active provinces from the province repository.
3. Account Settings now loads active branches from the current tenant snapshot,
   including each branch's ProvinceId.
4. Branch filtering now uses real tenant branch/province relationships.
5. The saved branch is the active membership's
   tblTenantMembership.DefaultBranchId.
6. Province is saved to the authenticated ApplicationUser through the existing
   UpdateProfileAsync operation.
7. A success Toast is shown only after both province and tenant branch persist.
8. Failure results are surfaced through error Toasts instead of success-shaped
   placeholder feedback.
9. The subscription selector now displays the current Standard or Open plan as
   read-only rather than presenting unrelated sample plans.

PREREQUISITES
-------------
Deploy these packages first, in this order:

  1. ApplicationReports_RuntimeCorrections_2026-09-26
  2. TenantUserRoleManagement_2026-09-29
  3. TenantUserRoleManagement_UIRefinement_2026-09-29
  4. IdentitySecurityUICleanup_2026-09-30
  5. TenantOwnerBranchAssignment_2026-09-30
  6. IdentityUserContextCorrections_2026-09-30

Also run the database script included in IdentityUserContextCorrections before testing
session timestamps.

FILES
