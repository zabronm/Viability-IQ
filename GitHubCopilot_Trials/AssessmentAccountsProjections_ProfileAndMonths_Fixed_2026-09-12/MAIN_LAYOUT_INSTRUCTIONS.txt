MAINLAYOUT_ASSESSMENT ROUTE UPDATE
==================================

The production file is:

    ViabilityIQ.Web\Components\Layout\MainLayout_Assessment.razor

Apply:

    MainLayout_Assessment_ROUTE_CHANGE.patch

Or make these two focused edits manually.


1. REPLACE THE NAVLINK
----------------------
Replace:

    <NavLink class="fa-nav-item py-0 my-0" href="assessment/debtors-creditors">

With:

    <NavLink class="fa-nav-item py-0 my-0" href="@DebtorsCreditorsUrl">


2. ADD THE URL PROPERTY
-----------------------
Inside the existing @code block, add:

    private string DebtorsCreditorsUrl =>
        SessionService.AssessmentId is long assessmentId && assessmentId > 0
            ? $"/assessment/debtors-creditors/{assessmentId}"
            : "/assessment/dashboards";


RESULT
------
For active assessment 123, the menu opens:

    /assessment/debtors-creditors/123

This matches the route on AssessmentAccs_Page:

    @page "/assessment/debtors-creditors/{AssessmentId:long}"

The fallback prevents a malformed URL when no assessment is active. The existing
HasDebtorsCreditorsData visibility condition remains unchanged.
