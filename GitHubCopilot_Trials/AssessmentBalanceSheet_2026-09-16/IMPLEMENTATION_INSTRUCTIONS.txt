ASSESSMENT BALANCE SHEET - IMPLEMENTATION
=========================================

Purpose
-------
Adds a third Balance Sheet tab to the Assessment Assets page.

The tab contains, in this order:
1. Assets Performance Metrics.
2. Dismissible and expandable balance-sheet findings (maximum six).
3. A complete projected M1-M12 assessment balance sheet.

Deployment
----------
1. Back up the current solution.
2. Deploy the latest income-aware cashflow projection implementation first.
3. Copy the contents beneath Files into the solution root, preserving paths.
4. Replace files when prompted.
5. Rebuild the solution.
6. Open /assessment/assets/{AssessmentId} and select Balance Sheet.

Printing
--------
The Balance Sheet tab includes a Print Full Page action using the same
viqAssetDetailsCharts print lifecycle as the Asset Summary and Asset Detail
pages. It expands findings for print, restores the screen state afterwards,
and formats the M1-M12 statement for A4 landscape output.

Balance-sheet sources
---------------------
Current assets:
- Positive bank balance
- Trade debtors
- Stock

Non-current assets:
- Closing fixed-asset net book value

Current liabilities:
- Bank overdraft
- Trade creditors

Non-current liabilities:
- Closing loans and borrowings

Projected net assets/equity:
- Total assets less recognised projected liabilities

The equity value is explicitly labelled as a balancing projected net-assets
amount. It is not presented as independently maintained share capital,
retained earnings or drawings because the current projection model does not
maintain those separate equity ledgers.

Alerts
------
Up to six findings are ranked by severity and may cover:
- Negative net assets
- Current-ratio weakness
- Recurring overdrafts
- High loan concentration
- Debtor concentration
- Inventory concentration
- Illiquid fixed-asset concentration

Each finding includes a recommendation. The panel supports See All Alerts,
See Less Alerts and dismiss.

Asset metrics
-------------
The replacement AssetSummaryKpiCardsComponent removes the hard-coded 94.2%
health rate. Asset health is now closing net book value divided by closing
gross asset value, capped between 0% and 100%.
