RECENT ASSESSMENTS SNAPSHOT - IMPLEMENTATION INSTRUCTIONS
========================================================

Copy these three files to:

ViabilityIQ.Web\Components\Pages\HomePageComponents\

- RecentAssessmentsSnapshotComponent.razor
- RecentAssessmentsSnapshotComponent.razor.cs
- RecentAssessmentsSnapshotComponent.razor.css

No service registration is required. The component uses existing services:

- IGenericDataRepository<AssessmentDto>
- ISessionService
- NavigationManager
- ToastService

CURRENT DATA RULE
-----------------

The component loads AssessmentDto records without filtering, orders them by
CreatedDate descending, and displays the first 10.

The snapshot uses separate columns for Case Number, Company Name, Owner, and
Period Start (Date). Period Start is populated from
AssessmentDto.AssessmentStartDate, not the assessment record's CreatedDate.

The future "assessments recently accessed by the current user" filter is
intentionally commented in LoadRecentAssessmentsAsync. The optional Active
filter is commented there as well. The current model does not contain a reliable
assessment-access-history field, so applying a user filter now would be
misleading.

When an access-history table or service is introduced, replace the commented
filter with a lookup of assessment IDs accessed by the authenticated user and
sort by the access timestamp.

HOME PAGE COMPATIBILITY
-----------------------

The existing HomePage markup can remain unchanged:

    <RecentAssessmentsSnapshotComponent Assessments="RecentAssessments" />

The legacy Assessments parameter remains temporarily for source compatibility,
but the snapshot now loads its own live AssessmentDto records.

The cleaner follow-up is to change the HomePage markup to:

    <RecentAssessmentsSnapshotComponent />

and remove the unused RecentAssessments dashboard-service request later.

OPEN-ASSESSMENT BEHAVIOUR
-------------------------

Selecting a row, its case-number link, or its Open button:

1. Finds the selected AssessmentDto.
2. Initializes ISessionService using the same pattern as AssessmentsPage.
3. Navigates to:

   /assessment/dashboards/{AssessmentId}

VALIDATION
----------

Run:

    dotnet build .\ViabilityIQ.Web\ViabilityIQ.Web.csproj

Then verify:

1. At most 10 rows appear.
2. Rows are ordered newest CreatedDate first.
3. Case Number, Company Name, Owner, and Period Start (Date) appear as separate
   columns.
4. Period Start displays AssessmentStartDate for each assessment.
5. Status badges and progress bars match each assessment.
6. Clicking a row opens the correct assessment dashboard.
7. View all opens /settings/assessments.
