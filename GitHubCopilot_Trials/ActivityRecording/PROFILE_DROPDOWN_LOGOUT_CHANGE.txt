PROFILE DROPDOWN - REQUIRED LOGOUT CHANGE
=========================================

The current ProfileDropdownComponent bypasses Logout.razor and AuthController.
It calls SignInManager.SignOutAsync directly, so no Logout activity is written.

Open:

ViabilityIQ.Web\Components\Pages\Identity\ProfileDropdownComponent.razor


1. REPLACE THE SIGN OUT BUTTON
------------------------------

Replace:

    <button class="profile-dropdown-item w-100 text-start border-0 bg-transparent"
            @onclick="LogoutAsync"
            type="button">
        <i class="bi bi-box-arrow-right me-2"></i> Sign Out
    </button>

with:

    <a href="/logout"
       class="profile-dropdown-item text-danger"
       @onclick="CloseProfileMenuImmediately">
        <i class="bi bi-box-arrow-right me-2"></i> Sign Out
    </a>


2. DELETE THE LogoutAsync METHOD
--------------------------------

Delete the complete method:

    private async Task LogoutAsync()
    {
        ...
    }

It must not call SignInManager.SignOutAsync from the interactive component.


3. OPTIONAL CLEANUP
-------------------

If no other markup or code in ProfileDropdownComponent uses these services,
remove:

    @inject SignInManager<ApplicationUser> SignInManager
    @inject NavigationManager NavigationManager
    @inject CustomAuthenticationStateProvider AuthenticationStateProvider

Keep UserManager and Logger if the component uses them elsewhere.


RESULTING FLOW
--------------

Profile dropdown link
    -> GET /logout
    -> user confirms
    -> POST /api/auth/signout-form
    -> AuthController writes mandatory Logout activity
    -> AuthController clears authentication cookie
    -> redirect /login

Any direct SignInManager.SignOutAsync or AuthService.LogoutAsync call outside
AuthController bypasses mandatory logout auditing.
