EXPLICIT ACTIVITY RECORDING EXAMPLES
====================================

The generic repository records Create, Update and Delete automatically.
Record semantic actions explicitly at the point where they actually succeed.


ASSESSMENT VIEW
---------------

After an assessment has been loaded and authorization has succeeded:

await ActivityLogWriter.RecordAsync(new ActivityLogWriteRequest
{
    Action = ActivityAction.View,
    EntityType = nameof(ActivityEntityType.Assessment),
    EntityId = assessment.AssessmentId,
    EntityName = assessment.CaseNumber,
    AssessmentId = assessment.AssessmentId,
    AssessmentName = assessment.CaseNumber,
    Module = "Assessments",
    Page = $"/assessment/dashboards/{assessment.AssessmentId}",
    Remarks = "Opened assessment workspace."
});


REPORT EXPORT
-------------

Only after the report file has been generated successfully:

await ActivityLogWriter.RecordAsync(new ActivityLogWriteRequest
{
    Action = ActivityAction.Export,
    EntityType = nameof(ActivityEntityType.Report),
    EntityId = reportId,
    EntityName = reportName,
    AssessmentId = assessmentId,
    Module = "Reports",
    Page = Navigation.Uri,
    Remarks = "Exported assessment report.",
    Metadata = new { Format = "PDF" }
});


APPROVAL
--------

Only after the approval transaction commits:

await ActivityLogWriter.RecordAsync(new ActivityLogWriteRequest
{
    Action = ActivityAction.Approve,
    EntityType = nameof(ActivityEntityType.Assessment),
    EntityId = assessmentId,
    EntityName = caseNumber,
    AssessmentId = assessmentId,
    AssessmentName = caseNumber,
    Module = "Assessment Review",
    Page = Navigation.Uri,
    Remarks = "Approved assessment."
});


IMPORTANT
---------

Never place passwords, reset tokens, access tokens, financial datasets, or full
request objects in Metadata. Metadata should contain small, non-secret context
such as output format, workflow stage, or changed field names.
