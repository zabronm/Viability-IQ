ZAB DATA TABLE ADVANCED - SERVER MODE USAGE

REFERENCE IMPLEMENTATIONS
- ClientPage
- AssessmentsPage
- BusinessPage

1. Add ServerField to each server-queryable column.

  new()
  {
      Title = "Client Name",
      ServerField = nameof(ClientDto.Client),
      Value = item => item.Client,
      Filterable = true
  }

ServerField must be a public property on TItem. The repository rejects unknown fields.
Set Searchable = false or Sortable = false where an operation is not meaningful.

2. Supply ServerData and a stable default sort.

  <ZabDataTableAdvanced TItem="ClientDto"
                        @ref="clientTable"
                        ServerData="LoadClientPageAsync"
                        DefaultSortField="@nameof(ClientDto.Client)"
                        Columns="@tableColumns"
                        ItemName="Client" />

3. Delegate the query to IReadOnlyRepository.

  private Task<DataTablePage<ClientDto>> LoadClientPageAsync(
      DataTableQuery query,
      CancellationToken cancellationToken) =>
      ClientRepository!.GetPageAsync(query, cancellationToken);

4. Refresh after mutations.

  if (clientTable is not null)
      await clientTable.RefreshAsync();

LOCAL MODE
Existing callers can continue supplying Items. Local search, filters, sorting and paging remain
available. Server mode is selected only when ServerData is supplied.

OUTPUT OPERATIONS
Existing OnPrintList, OnExportExcelList and OnEmailList callbacks remain compatible. In server
mode the component loads all filtered rows in 500-row batches before invoking the callback.
MaximumExportRows defaults to 10,000 and can be changed explicitly. Results above the limit
produce a visible error and must be narrowed before export.

SERVER QUERY LIMITS
IReadOnlyRepository clamps a single server page to 500 rows. Search and filter values use
parameterised LIKE expressions. Table/view and field identifiers are validated and quoted.
