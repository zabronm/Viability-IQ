PURPOSE
Refactors ZabDataTableAdvanced to match the application theme and adds first-class server-side
paging, global search, column filtering and column sorting.

DELIVERY SCOPE
- Existing Items-based pages remain compatible and continue to use local processing.
- ClientPage, AssessmentsPage and BusinessPage use server-side data operations.
- Other pages can be migrated incrementally using SERVER_MODE_USAGE.txt.

SERVER BEHAVIOUR
- SQL Server performs filtering, sorting, counting and OFFSET/FETCH paging.
- Search input is debounced (350 ms by default).
- In-flight requests are cancelled when a newer query starts.
- Stale responses cannot replace newer results.
- Search, filter and sort field names are allow-listed against public DTO properties.
- Values remain parameterised; user input is not concatenated into SQL.
- A deterministic secondary sort prevents records moving between pages.
- Server exports retrieve the complete filtered result in batches, up to the configured limit.
