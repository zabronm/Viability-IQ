VIABILITYIQ TENANT USER MANAGEMENT UI REFINEMENT
Package date: 2026-09-29

PURPOSE
-------
This package refines the working tenant user-management implementation delivered in:

  TenantUserRoleManagement_2026-09-29

It contains only the user-management page and form files changed by this refinement.

CHANGES
-------
1. Bootstrap breadcrumbs
   - /settings/users:
       Settings > Users
   - /settings/roles:
       Settings > User Groups / Roles
   - Settings links return to /settings/settings.

2. Global OffCanvas workflow
   - Add User opens TenantUserFormComponent through OffCanvasStateService.
   - Edit User opens the same component through OffCanvasStateService.
   - Assign Roles opens TenantRoleAssignmentComponent through OffCanvasStateService.
   - The previous centered modal overlays and their CSS were removed.
   - Forms use the established CanvasRequest, SaveResult and ResultCallback pattern.

3. Toast feedback
   - Page load failures use ToastService.
   - User create/update results use ToastService.
   - Role allocation results use ToastService.
   - Form components return SaveResult to their parent pages; they do not render inline
     success/error alerts.

PREREQUISITE
------------
Deploy and validate this package first:

  TenantUserRoleManagement_2026-09-29

This refinement does not repeat its database script, services, DTOs or security changes.

VALIDATION
----------
1. Sign in as Tenant Owner or Tenant Administrator.
2. Open /settings/settings and select Users.
3. Confirm the breadcrumb reads Settings > Users.
4. Click Settings in the breadcrumb and confirm /settings/settings opens.
5. Return to Users and click Add user.
6. Confirm the form slides in using the global off-canvas panel.
7. Trigger validation and save failures; confirm feedback appears as a Toast.
8. Save a valid user; confirm the success Toast, panel closure and refreshed list.
9. Edit a user; confirm the same off-canvas workflow.
10. Open /settings/roles.
11. Confirm the breadcrumb reads Settings > User Groups / Roles.
12. Click Assign roles; confirm the dedicated role component opens off-canvas.
13. Save role changes; confirm the success Toast and refreshed role list.
14. Confirm no centered modal overlay appears on either page.
