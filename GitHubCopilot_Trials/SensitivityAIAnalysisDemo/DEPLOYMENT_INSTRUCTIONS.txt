SENSITIVITY AI ANALYSIS DEMO — DEPLOYMENT INSTRUCTIONS
Generated: 2026-09-17

Purpose
-------
Adds an optional, provider-neutral AI interpretation demo as the fifth tab on the
existing Sensitivity Analysis page. Deterministic calculations remain authoritative.
The initial adapter uses Google Gemini's free developer tier and does not persist AI
results. GitHub Models is retired and is not used.

Prerequisite
------------
Deploy SensitivityAnalysisModule_2026-09-17 first. This package contains complete
replacement versions of the sensitivity page files and merged registration/config
files based on the supplied isolated integrated solution.

Deployment
----------
1. Back up the target repository.
2. Read MANUAL_PROJECT_FILE_MERGE.txt.
3. Copy the four files marked NEW in FILES_MANIFEST.txt.
4. Manually merge appsettings.json, Program.cs, both .csproj files and
   ServiceCollectionExtensions.cs using the exact additions in
   MANUAL_PROJECT_FILE_MERGE.txt. Do not blindly replace these files.
5. Merge or copy the three Sensitivity page files depending on whether they contain
   local changes.
6. Never write an API key into appsettings.json or commit one.
7. Build:
     dotnet restore ViabilityIQ.sln
     dotnet build ViabilityIQ.sln --no-restore
8. Configure a key, enable the demo, restart, and perform the manual checks below.
9. Deploy the updated Help PDF from:
     Files\ViabilityIQ.Web\wwwroot\documents\AssessmentAssumptionsHelp.pdf
   The editable source remains AssessmentAssumptionsHelp.html at the package root.

Obtain and configure a Gemini key
---------------------------------
1. Sign in to Google AI Studio:
     https://aistudio.google.com/app/apikey
2. Select or create a Google Cloud project.
3. Choose "Create API key" and store the value in a secret manager.

Local development (from the repository root):
  dotnet user-secrets set "SensitivityAI:ApiKey" "YOUR_KEY" --project ViabilityIQ.Web
  dotnet user-secrets set "SensitivityAI:Enabled" "true" --project ViabilityIQ.Web

Server environment-variable alternative:
  SensitivityAI__ApiKey=YOUR_KEY
  SensitivityAI__Enabled=true

Optional settings:
  SensitivityAI__Endpoint=https://generativelanguage.googleapis.com/v1beta/interactions
  SensitivityAI__Model=gemini-3.8-flash
  SensitivityAI__TimeoutSeconds=45
  SensitivityAI__MaxFindings=6

Privacy and free-tier warning
-----------------------------
Gemini free-tier data may be used by Google to improve its products. The UI requires
explicit consent before a call. Only calculated aggregate/month metrics, deterministic
flags, and known-driver numeric adjustments are sent. Business/owner/customer/supplier
names, arbitrary scenario names/descriptions, notes, user identity, assessment ID,
database entities, and source records are excluded. Requests use store:false.

Free-tier quotas/rate limits and Google terms can change. This demo is not recommended
for production without privacy, legal, security, data-governance, monitoring, provider
contract and operational reviews. No real API call was made during package validation.

Safety and validation
---------------------
- Gemini returns structured JSON with evidence keys from a request-specific allow-list.
- Viability.IQ maps those keys to authoritative calculated values for display.
- The request schema uses only Gemini-supported JSON Schema fields; application-side
  validation enforces text lengths, unique keys and the evidence allow-list.
- Unknown keys, malformed JSON, invalid severities, empty/oversized fields, duplicate
  rows and finding counts outside 1..MaxFindings are rejected.
- Raw model output, prompts, API keys and assessment data are not logged or displayed.
- Disabled, unconfigured, consent, timeout, 401/403, 429, service, safety, malformed
  response and cancellation outcomes are explicit. No fake success is substituted.

Manual checks
-------------
1. With defaults, open AI Analysis (Demo): verify Not configured and setup guidance.
2. Verify Generate is disabled until explicit consent is checked.
3. Verify changing assessment resets consent and clears prior analysis.
4. With an approved test key, generate baseline and adjusted-scenario analyses.
5. Verify evidence values match deterministic UI values and no raw output appears.
6. Verify Clear, Regenerate, responsive layout and Print / Save PDF.
7. Exercise invalid key and rate-limit/error handling in a controlled environment.

Changing provider later
-----------------------
Implement ISensitivityAiAnalysisService for the approved provider, retain the shared
request/result validation and evidence-key mapping controls, and replace the DI
registration. Do not change the deterministic calculation service.

Rollback
--------
Remove the four NEW files listed in FILES_MANIFEST.txt and restore every REPLACED file
from backup. No database rollback is required.
