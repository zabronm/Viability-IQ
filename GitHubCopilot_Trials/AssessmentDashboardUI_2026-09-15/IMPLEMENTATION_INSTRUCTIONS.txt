ASSESSMENT DASHBOARD UI - IMPLEMENTATION
========================================

Purpose
-------
This package replaces the hard-coded What-If dashboard with live cashflow
projection components. It does not modify production files automatically.

Prerequisites
-------------
Deploy the latest cashflow projection implementation first, including:
- ICashflowProjectionService
- CashflowProjectionResult and its income-aware monthly/summary fields
- IProjectionStateManager

Deployment
----------
1. Back up the current solution.
2. Copy the contents beneath Files into the solution root, preserving paths.
3. Replace the existing files when prompted.
4. Rebuild the solution.
5. Open /assessment/dashboards/{AssessmentId}.

Behavior
--------
- WhatIfPage calculates one immutable projection and passes it to all children.
- ProjectionChanged refreshes the complete dashboard once.
- Opening Stock and Closing Stock are replaced by Inventory Movement:
  Closing Stock less Opening Stock, with both balances shown in the note.
- The KPI ribbon contains no hard-coded percentages or VAT rates.
- Business Health Index uses live interest cover, margin of safety, asset
  turnover, and the calculated health score.
- Profit & Loss Performance Timeline uses monthly Profit Before Tax and labels
  every period M1 through M12.
- CashflowSummaryDashboardComponent and CashflowBusinessIndicatorComponent
  consume the same projection as the charts and KPI cards.

Validation
----------
After deployment, change Sales, Stock, Expenses, VAT or debtors/creditors data
and confirm that all dashboard components refresh to the same projection.
