AUTHORITATIVE FORMULAS
----------------------
Opening cash:

    M1 Opening Bank = Assessment.OpeningBalance_Bank
    M(n) Opening Bank = M(n-1) Closing Bank

Profit and loss values are VAT-exclusive:

    Revenue = active AssessmentSales monthly values

    COGS by sales category =
        Category Sales / (1 + MarkupPercentage / 100)

If markup is zero or missing, that category's stock purchases are used as a
visible fallback and a warning is raised.

    Gross Profit = Revenue - COGS

    Operating Expenses =
        all active AssessmentExpenses net monthly values
        + Assessment.MonthlyDirectorWagesAmountTotal

    EBITDA = Gross Profit - Operating Expenses
    EBIT = EBITDA - Depreciation
    Profit Before Tax = EBIT - Loan Interest - Overdraft Interest

Depreciation is never included in cash outflows.


CASH RECEIPTS AND PAYMENTS
--------------------------
When Assessment.blDebtorsCreditors == 1:

    Sales Receipts = profile-driven debtor collections
    Supplier Payments = profile-driven creditor payments

Otherwise:

    Sales Receipts = immediate monthly sales cash, VAT-inclusive per sales row
    Supplier Payments = immediate stock purchases, VAT-inclusive only when the
                        stock row has blIncludeVAT

Cash operating expenses include only AssessmentExpenses rows where
blSendToCashBook is true, grossed using TotalWithVAT / TotalNoVAT, plus director
wages.

VAT:

    VAT Payment = max(AssessmentVATTransactions.VATPayable, 0)
    VAT Refund = max(-AssessmentVATTransactions.VATPayable, 0)

VAT changes cash but is not a profit expense.

Loans:

    Loan Cash Payment =
        MetricTypeId 1 Expected Repayment
        + MetricTypeId 3 Extra Repayment

MetricTypeId 1 already contains the contractual installment. MetricTypeId 2
interest is not added to the installment again.

    Principal Repaid =
        max(Expected Repayment - Interest, 0) + Extra Repayment

No loan inflow is inferred from LoanAmount because the model has no reliable
indicator that a loan is newly disbursed during the projection.

Overdraft interest:

    Monthly Overdraft Interest =
        abs(negative opening bank)
        * Assessment.InterestOnOverDraft / 100 / 12

Asset movements:

    Addition = cash outflow
    Disposal = cash inflow
    Revaluation / Transfer = non-cash

MovementValue on a Disposal is assumed to be cash proceeds. If it represents
book value instead, add a separate disposal-proceeds field before relying on it.

Total cash:

    Total Inflows =
        Sales Receipts + Asset Disposal Proceeds + VAT Refunds

    Total Outflows =
        Supplier Payments
        + Cash Operating Expenses
        + VAT Payments
        + Loan Cash Payments
        + Overdraft Interest
        + Asset Purchases

    Net Cashflow = Total Inflows - Total Outflows
    Closing Bank = Opening Bank + Net Cashflow


BALANCE AND VIABILITY FORMULAS
------------------------------
    Closing Stock =
        max(0, Opening Stock + cumulative net stock purchases - cumulative COGS)

    Closing Loan =
        max(0, Opening Loan Balance - cumulative principal repaid)

    Current Assets =
        max(Closing Bank, 0) + Closing Debtors + Closing Stock

    Current Liabilities =
        Closing Creditors
        + Closing Loan Balance
        + max(-Closing Bank, 0)

The complete loan balance is conservatively classified as current because the
model has no current/non-current split.

    Current Ratio = Current Assets / Current Liabilities
    Contribution Margin Ratio = (Revenue - COGS) / Revenue
    Break-even Sales = Operating Expenses / Contribution Margin Ratio
    Margin of Safety = (Revenue - Break-even Sales) / Revenue
    Interest Cover = EBIT / Interest
    DSCR = EBITDA / Loan Cash Payments

NPV discounts the 12 monthly net cashflows at 10% nominal annual divided by 12.
Payback is displayed as unavailable because there is no authoritative initial
investment cashflow in the current model.


IMPORTANT MODEL LIMITATIONS
---------------------------
1. No cash-versus-credit field exists per AssessmentSales row. The assessment's
   blDebtorsCreditors flag is therefore the authoritative whole-assessment rule.
2. No fixed/variable expense classification exists. Break-even treats all
   operating expenses as fixed, which is conservative and explicitly labelled.
3. No current/non-current loan split exists.
4. Asset disposal MovementValue is assumed to equal proceeds.
5. No reliable new-loan disbursement flag exists.
