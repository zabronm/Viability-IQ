MAIN LAYOUT ENTITY BADGES
Generated: 2026-09-22

PURPOSE
Adds compact numeric badges to the Main Operations navigation links for:
- My Assessments
- Businesses
- Client Contacts
- Notifications (unread)

BEHAVIOR
- Resolves the signed-in ApplicationUser and establishes SessionService when its
  login context has not yet been initialized.
- Assessment, Business, and Client Contact totals are filtered by CreatedBy
  using the authenticated SessionService.UserId.
- The Notifications badge uses GetUnreadCountAsync for the authenticated user.
- Counts load concurrently when MainLayout initializes.
- Counts refresh when the user session changes and after an off-canvas form closes.
- Values above 99 are displayed as 99+.
- The badges remain visible when the sidebar is collapsed.
- The Notifications badge uses a distinct unread accent.

CORRECTION
The original package assumed EstablishUserSession had already been called. The
application defines that method but does not currently invoke it elsewhere, leaving
SessionService.UserId at its default value. MainLayout now initializes the shared
session from AuthenticationStateProvider and IAuthenticationService before counting.
