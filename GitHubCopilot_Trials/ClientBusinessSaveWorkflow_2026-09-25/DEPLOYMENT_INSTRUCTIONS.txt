CLIENT AND BUSINESS SAVE WORKFLOW
=================================

Purpose
-------
This package extends the standardized off-canvas save workflow to:
- BusinessFormComponent and BusinessPage
- ClientFormComponent and ClientPage
- MainLayout Business and Client count indicators

Behavior
--------
New Business or Client:
- Saves with the authenticated user as CreatedBy through GenericDataRepository.
- Publishes SavedAndNew.
- Refreshes the parent server-side grid.
- Refreshes the corresponding MainLayout count immediately.
- Clears the form and keeps the off-canvas open for another record.

Existing Business or Client:
- Publishes SavedAndClose.
- Refreshes the parent server-side grid and MainLayout count.
- Closes the off-canvas.

Delete:
- Refreshes the parent grid.
- Notifies MainLayout to refresh entity counts.

Deployment
----------
1. Back up or commit the current source tree.
2. Copy the complete contents of the Files folder to the solution root.
3. Preserve the relative paths and overwrite the listed files.
4. This package is cumulative for the shared SaveResult, OffCanvasStateService,
   and MainLayout files used by the earlier data-entry save workflow package.
5. Build:

   dotnet build .\ViabilityIQ.sln --no-restore --nologo --verbosity quiet

Validation
----------
The package was overlaid onto the synchronized validation solution together
with the earlier save-workflow package. The complete solution built with
0 errors. Existing unrelated warnings remain.
