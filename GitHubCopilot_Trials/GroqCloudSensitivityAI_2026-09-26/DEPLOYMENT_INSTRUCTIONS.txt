GROQCLOUD SENSITIVITY AI - DEPLOYMENT INSTRUCTIONS
Package date: 2026-09-26

PURPOSE
-------
This package adds GroqCloud as a second, independent sensitivity-analysis AI
provider. It does not remove or replace the existing Gemini tab.

The GroqCloud tab provides:
- Explicit provider-specific consent.
- Authoritative KPI cards.
- Monthly closing-cash and profit-before-tax visualizations.
- Baseline-versus-current financial metrics.
- AI executive summary and prioritized recommendations.
- Printable / Save PDF output.

The application sends only calculated sensitivity metrics, monthly projections,
scenario adjustments, and deterministic flags. It excludes the assessment ID,
business identity, names, notes, and source records. AI output never replaces or
recalculates the application's deterministic figures.

PREREQUISITES
-------------
- .NET 8 SDK/runtime.
- An existing ViabilityIQ deployment containing the Sensitivity Analysis and
  Gemini AI Analysis implementation.
- Outbound HTTPS access to api.groq.com.
- A GroqCloud account and API key.

BACK UP FIRST
-------------
Back up the application files and configuration before deployment. Preserve any
local changes when merging the staged files.

DEPLOYMENT
----------
1. Stop the application or IIS application pool.
2. Open this package's Files directory.
3. Copy each file to the matching path under the production solution root.
4. Merge rather than blindly overwrite if production has changed since this
   package was prepared.
5. From the solution root, run:

   dotnet restore .\ViabilityIQ.sln
   dotnet build .\ViabilityIQ.sln --no-restore

6. Configure the GroqCloud API key using one of the secure methods below.
7. Restart the application.

OBTAINING A GROQCLOUD API KEY
-----------------------------
1. Visit https://console.groq.com/.
2. Create a GroqCloud account or sign in.
3. Open API Keys in the GroqCloud console. The direct page is normally:
   https://console.groq.com/keys
4. Select Create API Key.
5. Give the key a descriptive name, such as "ViabilityIQ Production".
6. Create the key and copy it immediately. The complete key may only be shown
   once.
7. Store it in an approved secret manager. Do not paste it into appsettings.json,
   source code, deployment scripts, tickets, email, or source control.
8. Review https://console.groq.com/docs/models and the GroqCloud console before
   deployment. Available models, free/developer usage, pricing, and rate limits
   can change.

CONFIGURATION OPTIONS
---------------------
The committed appsettings.json contains only a commented example with an empty
ApiKey. Use environment variables or .NET user-secrets for the real credential.

Option A - current PowerShell process (local test only):

  $env:GroqSensitivityAI__Enabled = "true"
  $env:GroqSensitivityAI__ApiKey = "<your-groq-api-key>"
  $env:GroqSensitivityAI__Model = "openai/gpt-oss-20b"
  dotnet run --project .\ViabilityIQ.Web\ViabilityIQ.Web.csproj

Option B - Windows user environment variables:

  [Environment]::SetEnvironmentVariable(
      "GroqSensitivityAI__Enabled", "true", "User")
  [Environment]::SetEnvironmentVariable(
      "GroqSensitivityAI__ApiKey", "<your-groq-api-key>", "User")
  [Environment]::SetEnvironmentVariable(
      "GroqSensitivityAI__Model", "openai/gpt-oss-20b", "User")

Sign out/in or restart the hosting process after setting persistent variables.

Option C - .NET user-secrets (development):

  dotnet user-secrets set "GroqSensitivityAI:Enabled" "true" `
      --project .\ViabilityIQ.Web\ViabilityIQ.Web.csproj
  dotnet user-secrets set "GroqSensitivityAI:ApiKey" "<your-groq-api-key>" `
      --project .\ViabilityIQ.Web\ViabilityIQ.Web.csproj
  dotnet user-secrets set "GroqSensitivityAI:Model" "openai/gpt-oss-20b" `
      --project .\ViabilityIQ.Web\ViabilityIQ.Web.csproj

Option D - hosted environments:
- IIS: add the variables to the application pool/process environment and recycle
  the application pool. Restrict access to the server configuration.
- Azure App Service: add the names under Configuration > Application settings;
  mark the API-key setting as a deployment-slot setting where appropriate.
- Containers: inject the variables through the platform secret facility. Do not
  put the key in the image or Dockerfile.

SUPPORTED SETTINGS
------------------
GroqSensitivityAI__Enabled
  Must be true for the provider to be available.

GroqSensitivityAI__ApiKey
  Required secret obtained from GroqCloud.

GroqSensitivityAI__Endpoint
  Defaults to https://api.groq.com/openai/v1/chat/completions. For credential
  safety, this implementation accepts only HTTPS requests to api.groq.com.

GroqSensitivityAI__Model
  Defaults to openai/gpt-oss-20b, which supports strict structured output at the
  time this package was prepared. Verify current availability before production
  deployment.

GroqSensitivityAI__TimeoutSeconds
  Request timeout. Allowed application range: 5-120 seconds. Default: 60.

GroqSensitivityAI__MaxFindings
  Maximum recommendations. Allowed application range: 1-10. Default: 6.

GroqSensitivityAI__MaxCompletionTokens
  Maximum model output tokens. Allowed application range: 500-6000.
  Default: 2500.

VALIDATION
----------
1. Open an assessment with projection data.
2. Open Sensitivity Analysis.
3. Confirm the existing "AI Analysis (Demo)" Gemini tab still appears.
4. Open "GroqCloud AI".
5. Confirm the provider indicator says "Configured".
6. Confirm KPI cards, both monthly visualizations, and the comparison table use
   the current deterministic result.
7. Read the disclosure, provide consent, and generate the analysis.
8. Confirm an executive summary and recommendations table appear.
9. Confirm the evidence values match the authoritative cards/tables.
10. Use Print / Save PDF and verify that the report is printable.
    The print preview must include the complete active report, including content
    below the on-screen scroll position; application navigation and scrollbars
    must not appear.
11. Clear the result and confirm it is removed from the page.
12. Run another scenario and confirm the prior GroqCloud result is cleared.

ERROR GUIDANCE
--------------
- Not configured: verify Enabled, ApiKey, HTTPS endpoint, and api.groq.com host.
- Unauthorized: replace or correct the API key.
- Rate limited: wait and retry, or review the current account limits.
- Request rejected: verify that the configured model is active and supports
  structured output.
- Timeout/unavailable: verify outbound network access and retry later.

SECURITY NOTES
--------------
- Rotate the key immediately if it is exposed.
- Give application and deployment administrators only the access they need.
- Keep provider terms, retention, data-processing, and regional requirements
  under review before enabling production use.
- Generated content is advisory, is not persisted by this page, and must be
  reviewed by a qualified user.
