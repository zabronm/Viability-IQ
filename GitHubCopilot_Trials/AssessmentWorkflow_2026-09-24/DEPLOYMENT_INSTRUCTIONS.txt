ASSESSMENT WORKFLOW AND ANALYTICS - DEPLOYMENT INSTRUCTIONS
==========================================================

Package purpose
---------------
Adds calculated assessment readiness, lifecycle status actions, six assessment KPI
cards, improved system insights, and a full analytics page at /analytics.

Prerequisites
-------------
1. Back up the application files and database.
2. Ensure the MainLayout/SessionService user-session initialization delivered in
   MainLayout_EntityBadges_2026-09-22 is already present. The lifecycle metrics are
   intentionally scoped to the authenticated user and do not fall back to all users.

Deployment order
----------------
1. Stop the application.
2. Run this idempotent SQL script against the application database:
   Files\DatabaseScripts\2026-09-24_AssessmentLifecycleAudit.sql
3. Copy the contents of Files into the production solution root, preserving the
   production-relative folder structure. DatabaseScripts is deployment support and
   does not need to be copied into the deployed web application.
4. Rebuild and publish the solution using the normal production process.
5. Start the application.

Database changes
----------------
The SQL script adds nullable lifecycle audit columns to dbo.tblAssessments:
- CompletedDate
- CompletedBy
- ReopenedDate
- ReopenedBy

The script also backfills completion details for existing completed assessments from
ModifiedDate and ModifiedBy. It is safe to run more than once.

Workflow behavior
-----------------
- Draft (StatusId 1) automatically advances to In Progress when readiness is above 0%.
- In Progress (StatusId 2) can move to Ready for Review when readiness reaches 100%.
- Ready for Review (StatusId 3) can be marked Completed after confirmation and a
  fresh readiness validation.
- Completed (StatusId 4) can be re-opened to In Progress after confirmation.
- ProgressPercentage stores the calculated readiness score.
- Completion and re-open transitions record dedicated date/user audit values.

KPI definitions
---------------
- Total Assessments: active assessments created by the authenticated user.
- Draft: StatusId 1.
- In Progress: StatusId 2.
- Ready for Review: StatusId 3.
- Ready for Assessment: 100% readiness and not completed.
- Completed: StatusId 4.

Validation
----------
Validated in the synchronized integrated solution with:
dotnet build .\ViabilityIQ.sln --no-restore --nologo --verbosity quiet

Result: 0 errors. Existing solution warnings remain.

Rollback
--------
Restore the backed-up application files. The four added database columns are nullable
and can remain without affecting the previous application. Remove them only after
confirming no lifecycle audit data must be retained.
